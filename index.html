산림청 임상도 기반 사슴벌레 채집 지도

참나무 고목 지도란?

산림청 공식 임상도(1~9영급) 데이터를 기반으로 전국의 참나무류 서식 구역을 시각화한, 사슴벌레·장수풍뎅이 채집을 위한 지도입니다. 어디에 참나무 노령림이 있는지 한눈에 확인할 수 있도록 만들었습니다.

주요 기능

  • 영급(수령)·수종 계열별 색상 구분 표시, 세부 필터 On/Off
  • 키워드로 장소 검색 및 카카오 로드뷰 확인 (숲 폴리곤 미니맵 포함)
  • 원하는 장소를 별/동그라미/자동차 아이콘으로 저장, 폴더로 정리
  • 실시간 GPS 위치 추적 및 진행 방향 표시
  • 기상청 실측 데이터 기반 실시간 기온·하늘상태 표시 (지도 이동 시 자동 갱신)
  • 저장 장소 두 곳을 출발/도착으로 지정해 카카오맵 자동차 길찾기 연동
  • 구글 계정으로 로그인 시 여러 기기 간 저장 장소 동기화
